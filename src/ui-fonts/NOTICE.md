# UI fonts

These two variable fonts style the Framecut interface. `build.py` embeds them as base64 `@font-face` rules. They are separate from `src/fonts/`, which holds the text-clip title fonts.

- **Space Grotesk** (`space-grotesk-latin.woff2`), (c) Florian Karsten. SIL Open Font License 1.1.
- **Atkinson Hyperlegible Next** (`atkinson-hyperlegible-next-latin.woff2`), (c) Braille Institute of America, Inc. SIL Open Font License 1.1.

SIL Open Font License 1.1: https://openfontlicense.org/open-font-license-official-text/

Copies are the self-hosted files from the GP Song Tools menu (`toolsmenu/fonts/`).
